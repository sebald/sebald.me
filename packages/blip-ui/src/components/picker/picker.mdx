# Picker

A list the player moves through with a cursor: the title menu, options,
the choices in a duel. It is always open and always listening, so one
picker at a time is `active`. Lists of choices are a Picker, not a column
of buttons.

## Anatomy

1. **Cursor**, a pixel triangle on the current row
2. **Row**, the label; the current one is white, an accent one is primary
3. **Rail**, beside a list that does not fit: an arrow lit where there is
   more, and a track with the view's place on it
4. **Note**, a small window beside the list's own, at the current row

## States

An item can be selected (the cursor is on it), accent, disabled or dimmed.

<Canvas of={PickerStories.Overview} />

| Item option | Effect                                                                  |
| ----------- | ----------------------------------------------------------------------- |
| `accent`    | The loud one: primary colour, blinking (steady under reduced motion)    |
| `disabled`  | Dimmed and reachable, but it bumps when picked. Give it a `note` why    |
| `dim`       | A label opacity from 0 to 1, for a wrong choice you don't want to hide  |
| `note`      | What it does, or why it is off, in a window beside the list             |
| `onStep`    | Left and right on the row, for a setting (see Setting)                  |
| `back`      | It leaves: Back or Cancel sound like stepping back, not like confirming |
| `apart`     | Room above it, the first of a group                                     |

## Usage

- **Do** put a picker in a Window, with a Legend that names the keys.
- **Do** keep a disabled item in the list and say why in its note.
- **Don't** hide what is not available. Nothing in a menu is hidden.
- **Don't** have two active pickers. When a Confirm opens over a menu, set
  the menu's `active` to false.

## The description box

The note is rendered into the closest `[data-stage]` (what `Pixels`
sets), so no window can cut it off. It goes beside the list's window, on
the right or on the left where the right has no room. The stage's width
is measured; pass `stageWidth` (in stage pixels) to set it. On the tall
layout it goes under the window, as wide as it.

## Input

- Up and down, or W and S, move; the list wraps
- Left and right, or A and D, step an item that has `onStep`
- Enter or Space picks the current item
- Hovering a row moves the cursor; a click or tap picks it
- Under a finger there is no cursor: only a row with a note is marked

## Sound

`move` when the cursor moves or a value steps, `confirm` when an item is
picked, `back` for a `back` item and `bump` for a disabled one.

## Accessibility

- A `<ul>` named by `label` with a button per row; the current one has
  `aria-current`, a disabled one `aria-disabled`
- The note is an `aria-live` region
- The focus ring shows for the keyboard only (`:focus-visible`)
