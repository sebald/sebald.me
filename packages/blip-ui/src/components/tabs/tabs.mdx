# Tabs

A window with pages, for a screen that has them: a glossary by role, a
codex by chapter, a duel's pools and its log. The panel is the window; the
tabs hang from its top left as folder tabs, drawn in the window's layers.
Built on Base UI's Tabs, with the game's pixel look.

<Canvas of={TabsStories.Default} />
<Controls of={TabsStories.Default} />

```tsx
<Tabs defaultValue="pm">
  <TabList aria-label="Pools">
    <Tab value="pm">PM</Tab>
    <Tab value="dev">Dev</Tab>
  </TabList>
  <TabPanel value="pm">
    …
    <Legend keys={[['←→', 'pool']]} touch="Tap a tab" />
  </TabPanel>
</Tabs>
```

## Anatomy

1. **TabList**, the row, from the window's top left, with an arrow at
   each end
2. **Tab**, a folder tab in the window's layers (ink, frame, inner line).
   The idle ones stand on the window's top edge, dimmer; the current one
   reaches over the edge and opens into the window, with no line between
   them: the window's frame and inner line turn up into the tab's. All
   the labels sit on one line, and the arrows centre on them
3. **TabPanel**, what the tab shows, drawn as the window. A `Legend` last
   in it sits along its bottom edge, as in a `Window`

<Canvas of={TabsStories.Overview} />

Only the current panel is shown, so a panel sizes the window: give the
set a fixed size from outside when the pages differ in length.

## Usage

- **Do** give each `Tab` a `value` and the `TabPanel` the same one.
- **Do** name the list with `aria-label`.
- **Do** use Tabs for a window with pages, not a `Window` with tabs put
  on it.
- **Do** turn on `keys` on a screen where nothing else uses left and right.
- **Don't** use tabs for steps in a flow. They are pages that can be
  visited in any order.

## Input

- Click or tap a tab
- Left and right (or Home and End) on a focused tab, as Base UI does
- With `keys`, left and right (or A and D) switch from anywhere and wrap
  around
- The arrows at the row's ends switch too, round past the ends (for a
  pointer; they are not in the tab order, the keys do that)

## Sound

`move` when the active tab changes.

## Accessibility

Base UI provides `tablist`, `tab` and `tabpanel`, with `aria-selected`,
`aria-controls` and a roving tab stop.
