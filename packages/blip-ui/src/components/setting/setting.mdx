# Setting

A value between two step arrows, for a row that is a setting: Mode
◀ Normal ▶. It shows the value; in a menu, `PickerSetting` draws it and
takes the `Picker`'s keys, and in a form a `Stepper` draws the same arrows (`Step`) and takes its own. Both show the arrows only on the row Left and Right reach (the cursor's, or the one under the pointer) and always under a finger; on its own a `Setting` always shows them.
The same look in both, so a choice reads alike wherever it is.

## Anatomy

1. **Left step**, a pixel triangle, dim only at a range's first value
2. **Value**, centred in six characters so the arrows stay put
3. **Right step**, dim only at a range's last value

## Usage

- **Do** use `PickerSetting` in a Picker: it draws the Setting and takes
  the keys.
- **Do** use `Stepper` in a form: it draws the same arrows, takes the
  focus and the keys, and sends its value with the form.
- **Do** show every setting this way, even one of two values (On and
  Off), in a menu and in a form, so they all read and work alike.
- **Do** let a choice go round: left from the first value goes to the
  last, both arrows lit (Mode, Music On/Off). Leave `first` and `last`
  unset.
- **Do** stop a range at its ends: a volume or a brightness has a min and
  a max, and 10 jumping to 0 would be a surprise. Set `first` and `last`
  so the arrow at an end dims.
- **Don't** use it alone: it has no keys or click of its own.

## Accessibility

The arrows are hidden from assistive technology. Name the setting and its
value in the row's label.
