# Setting

A value between two step arrows, for a menu row that is a setting: Mode
◀ Normal ▶. It shows the value; the keys that change it are the Picker's
`onStep`.

<Canvas of={SettingStories.Default} />
<Controls of={SettingStories.Default} />

## Anatomy

1. **Left step**, a pixel triangle, dim at the first value
2. **Value**, centred in six characters so the arrows stay put
3. **Right step**, dim at the last value

<Canvas of={SettingStories.Overview} />

## Usage

- **Do** put it in the label of a Picker item that has `onStep`.
- **Do** set `first` and `last` so the arrows show where the values end.
- **Don't** use it alone: it has no keys or click of its own.

## Accessibility

The arrows are hidden from assistive technology. Name the setting and its
value in the row's label.
