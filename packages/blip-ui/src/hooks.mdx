# Hooks

What a screen needs that has no look: input, time, the scale, what a
screen reader hears. Each one is a shared helper, not a component.

## Input

| Hook                               | Does                                                                                                                                                                                                          |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useKeys(handlers, active, quiet)` | Key handlers by `event.key`, while mounted. Escape sounds like going back unless `quiet`                                                                                                                      |
| `useAnyKey(onPress, active)`       | Any key or a tap: press start, tap to continue, leave the demo. A tap counts on its click; the press that opened the screen does not count                                                                    |
| `useIdle(ms, onIdle, active)`      | `onIdle` once nothing was pressed or touched for `ms`: the attract mode                                                                                                                                       |
| `useInputKind()`                   | `keys` or `touch`, by the last input, so a legend names the right thing                                                                                                                                       |
| `useOnTop()`, `useKeyLayer(open)`  | The layers keys go to. A part that listens checks `useOnTop()` when a key comes in; a `Dialog` opens a layer for its parts, so the screen under it hears nothing. Only for a part of your own that is a layer |

The kit's listeners run in the capture phase, so a dialog's popup can't
stop a key on its way, and they leave alone the keys a focused element
handles itself: typing in a field, the arrows a focused row of tabs moves
with.

## Time, scale, sound

| Hook                      | Does                                                                                                                  |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `useClock(running, tick)` | Ticks since mount, for a piece that animates on its own; stopped, it rests at zero                                    |
| `usePixels()`             | The scale, the tall layout and the rows of the stage around a piece                                                   |
| `useScroll(ref, key)`     | How far a list is scrolled and how much of it shows                                                                   |
| `useFeedback()`           | Play a UI sound by what happened (`move`, `confirm`, `back`…); the game decides what plays                            |
| `useAnnounce()`           | Say something to a screen reader, politely: a line, a description, a result. Every stage holds one live region for it |
| `useFullscreen()`         | Whether the game is fullscreen; `toggleFullscreen()` and `canFullscreen()` go with it                                 |
