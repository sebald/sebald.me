# Quest log

Players take on quests and then forget what they were doing. Add a quest log
with the quests from the game state (`quests`).

- Open quests first, done ones after, kept apart.
- Each quest shows its name and who gave it. An open quest also shows what to
  do next.
- Choosing a quest shows its whole description.
- Works with the keyboard and on a touch screen.

Register it as `quests` so it opens with `?screen=quests`.
